**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Checks whether a signature over some data was made by the private key that belongs to a given public key, and answers true or false. It is used to check signatures from registration-client machines (TPM or software keys) and signatures the key manager itself made with `POST /v1/keymanager/cssign`. The server does not need to know the key in advance — the caller supplies it.

**Request & response**

```json
{
  "id": "string", "version": "string", "requesttime": "2026-11-10T10:00:00.000Z", "metadata": {},
  "request": {
    "data": "SGVsbG8gTU9TSVA",
    "signature": "<URL-safe Base64 signature>",
    "publicKey": "<URL-safe Base64 public key>",
    "clientType": "LOCAL"
  }
}
```
On success:
```json
{ "response": { "verified": true }, "errors": null }
```
`data`, `signature` and `publicKey` are required, URL-safe Base64. `clientType` (`TPM`, `ANDROID`, `LOCAL`) is optional: it defaults to `LOCAL` (an X.509 RSA key, SHA-256 with RSA), and a TPM-format key is recognised automatically. `verified` false means the signature does not match; a malformed key or signature comes back as HTTP 500.

**Who can call it**

ZONAL_ADMIN, GLOBAL_ADMIN, INDIVIDUAL, ID_AUTHENTICATION, TEST, REGISTRATION_ADMIN, REGISTRATION_SUPERVISOR, REGISTRATION_OFFICER, REGISTRATION_PROCESSOR, PRE_REGISTRATION_ADMIN and RESIDENT (default configuration). Anyone else is refused. See README.md § How authentication works in this module.
