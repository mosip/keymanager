**About this endpoint**

**What this endpoint does**

Decrypts a package that was encrypted to the key manager's own "client crypto" encryption key (the key from `POST /v1/keymanager/tpmencryption/publickey`, usually via `POST /v1/keymanager/tpmencrypt`) and returns the original data. On a server pod there is normally no hardware TPM, so the server's key is a software RSA-2048 key created on first use (local mode). Anything encrypted for a different key cannot be opened here.

**Request & response**

```json
{
  "id": "string", "version": "string", "requesttime": "2026-11-10T10:00:00.000Z", "metadata": {},
  "request": {
    "value": "<URL-safe Base64 encrypted package>",
    "publicKey": "<any non-blank value>"
  }
}
```
On success:
```json
{ "response": { "value": "SGVsbG8gTU9TSVA" }, "errors": null }
```
`value` is the encrypted package, URL-safe Base64. `publicKey` must be non-blank but is not used. The result is the original data, URL-safe Base64 without padding. Altered data gives `KER-FSE-004` (HTTP 200); data for another key or too short gives HTTP 500 `KER-KMS-500`.

**Who can call it**

ZONAL_ADMIN, GLOBAL_ADMIN, INDIVIDUAL, ID_AUTHENTICATION, TEST, REGISTRATION_ADMIN, REGISTRATION_SUPERVISOR, REGISTRATION_OFFICER, REGISTRATION_PROCESSOR, PRE_REGISTRATION_ADMIN and RESIDENT (default configuration). Anyone else is refused. See README.md § How authentication works in this module.
