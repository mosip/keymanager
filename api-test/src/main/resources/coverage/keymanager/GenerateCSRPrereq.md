**About this endpoint**

**What this endpoint does**

This file covers a setup step, not a separate API. Before the CSR tests run, the suite asks the key manager's generate-master-key endpoint to create a master key for its own CSR test application (`<RUNCONTEXT>AUTOMATIONCSR`). The CSR endpoint can only build a signing request for a key that already exists, so this call has to succeed first. The endpoint itself — what it does, its request and response, and its rules — is described in keymanager/GenerateMasterKey.md.

**Request & response**

Same as generateMasterKey: the setup sends
```json
{
  "id": "io.mosip.keymanager.generateMasterKey",
  "version": "1.0",
  "requesttime": "2026-11-10T10:00:00.000Z",
  "metadata": {},
  "request": { "applicationId": "<RUNCONTEXT>AUTOMATIONCSR", "referenceId": "", "force": false }
}
```
and gets back a PEM `certificate` with `issuedAt`, `expiryAt` and `timestamp`.

**Who can call it**

The same users as generateMasterKey (see keymanager/GenerateMasterKey.md). See README.md § How authentication works in this module.
