**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Makes a one-way Argon2id hash of a value (for example an ID number), so other services can store and compare the hash instead of the value. The caller can send its own salt to get a repeatable hash; without one, the key manager makes a fresh salt and returns it.

**Request & response**

```json
{
  "id": "string",
  "version": "1.0",
  "requesttime": "2026-11-10T10:00:00.000Z",
  "metadata": {},
  "request": { "inputData": "1234567890", "salt": "<optional, base64url>" }
}
```
`inputData` is required and must not be blank.

On success:
```json
{ "response": { "hashValue": "<base64url, 32 bytes>", "salt": "<base64url salt used>" }, "errors": null }
```
Failures come back in `errors[]`, e.g. `KER-KMS-005` (blank input), `KER-CRY-003` (salt not base64url).

**Who can call it**

By default ZONAL_ADMIN, GLOBAL_ADMIN, INDIVIDUAL, ID_AUTHENTICATION, TEST, REGISTRATION_ADMIN, REGISTRATION_SUPERVISOR, REGISTRATION_OFFICER, REGISTRATION_PROCESSOR, PRE_REGISTRATION_ADMIN and RESIDENT. Anyone else is refused. See README.md § How authentication works in this module.
