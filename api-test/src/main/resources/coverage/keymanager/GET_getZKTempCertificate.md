**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Part of the one-time key migration from an old key manager to a new one. Before the zero-knowledge (ZK) data-encryption keys can be moved, the old system needs a public key to wrap them with in transit. This call hands out that temporary certificate — creating a new temporary key pair (valid for one day) if none is current, otherwise returning the existing one. The keys wrapped with it are then sent to `POST /migrateZKKeys`.

This creates a key in the keystore. It is meant for an isolated migration environment and must never be mixed into a normal test run; run it last.

**Request & response**

A plain `GET` with no parameters:
```
GET /v1/keymanager/getZKTempCertificate
```
On success:
```json
{
  "response": {
    "certificate": "-----BEGIN CERTIFICATE-----\n...",
    "timestamp": "2026-11-11T10:00:00.000Z"
  },
  "errors": null
}
```

**Who can call it**

Only users with the KEY_MIGRATION_ADMIN role (default configuration) — ordinary administrators are refused. See README.md § How authentication works in this module.
