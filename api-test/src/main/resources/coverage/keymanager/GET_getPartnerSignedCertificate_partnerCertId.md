**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Returns both versions of a partner's certificate in one call: the certificate exactly as the partner uploaded it (signed by the partner's own CA) and the copy MOSIP issued for the same key, signed by MOSIP's partner-signing (PMS) key. Partner management uses it to show and hand out both certificates.

**Request & response**

A plain `GET` with the partner certificate ID returned by uploadPartnerCertificate:
```
GET /v1/keymanager/getPartnerSignedCertificate/7a6b5c4d-....
```
On success:
```json
{
  "response": {
    "caSignedCertificateData": "-----BEGIN CERTIFICATE-----\n...",
    "mosipSignedCertificateData": "-----BEGIN CERTIFICATE-----\n...",
    "timestamp": "2026-11-10T10:05:00.000Z"
  },
  "errors": null
}
```
Failures come back in `errors[]` with HTTP 200: `KER-PCM-010` (blank ID), `KER-PCM-012` (no partner certificate with that ID).

**Who can call it**

ZONAL_ADMIN, GLOBAL_ADMIN, PMS_ADMIN and PMS_USER (default configuration). Anyone else is refused. See README.md § How authentication works in this module.
