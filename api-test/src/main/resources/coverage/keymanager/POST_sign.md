**About this endpoint**

**What this endpoint does**

The original (now deprecated) signing call: it signs a piece of text with the key manager's own signing key (KERNEL / SIGN) and returns the signature with the time it was made. It is kept for older callers; newer services use jwtSign, jwsSign or signV2. Signatures it makes are checked with the validate endpoint.

**Request & response**

```json
{
  "id": "string",
  "version": "1.0",
  "requesttime": "2026-11-10T10:00:00.000Z",
  "metadata": {},
  "request": { "data": "Test data" }
}
```
`data` is the text to sign and is required.

On success:
```json
{
  "response": { "signature": "Zm9vYmFy...", "timestamp": "2026-11-10T10:00:00.000Z" },
  "errors": null
}
```
A missing `data` returns `KER-KMS-005`.

**Who can call it**

ZONAL_ADMIN, GLOBAL_ADMIN, INDIVIDUAL, ID_AUTHENTICATION, TEST, REGISTRATION_ADMIN, REGISTRATION_SUPERVISOR, REGISTRATION_OFFICER, REGISTRATION_PROCESSOR, PRE_REGISTRATION_ADMIN and RESIDENT (default configuration). Anyone else is refused. See README.md § How authentication works in this module.
