**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Shows which authentication features a license key has been granted. A license key is issued to a TSP (an authentication partner) with `POST /license/generate`; permissions such as "OTP Trigger" or "eKYC - Full" are attached to it with `POST /license/permission`. This call reads that list back so a caller can see what the partner holding the key may do.

**Request & response**

A plain `GET` with two required query parameters:
```
GET /v1/keymanager/license/permission?tspId=TSP001&licenseKey=aB3dE5gH7jK9mN1p
```
On success:
```json
{
  "response": { "permissions": ["OTP Trigger", "eKYC - Full"] },
  "errors": null
}
```
Errors come back with HTTP 200 and an `errors` list: `KER-LKM-001`/`KER-LKM-006` blank TSP ID / license key, `KER-LKM-004` key not issued to that TSP, `KER-LKM-005` key expired, `KER-LKM-009` no permissions mapped yet, `KER-KMS-005` a parameter missing.

**Who can call it**

Any logged-in user — there is no role rule on this endpoint (row _003 flags this as a possible bug). See README.md § How authentication works in this module.
