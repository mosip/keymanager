**About this endpoint**

**What this endpoint does**

Searches the CA and sub-CA certificates that have been uploaded to the key manager (the trust store partners' certificates are checked against) and returns them one page at a time. Partner administrators use it to see which CAs are trusted, filter them by type, domain, subject, issuer or dates, and pick a certificate ID for other calls such as the trust-path download.

**Request & response**

```json
{
  "id": "string", "version": "string", "requesttime": "2026-11-10T10:00:00.000Z", "metadata": {},
  "request": {
    "caCertificateType": "ROOT",
    "partnerDomain": "AUTH",
    "excludeMosipCA": false,
    "certId": "", "issuedTo": "", "issuedBy": "",
    "validFromDate": null, "validTillDate": null, "uploadTime": null, "expiringWithinDate": null,
    "sortByFieldName": "createdtimes", "sortOrder": "ASC",
    "pageNumber": 1, "pageSize": 10
  }
}
```
Every filter is optional; text filters are case-insensitive "contains" searches, date filters match on the calendar day. `caCertificateType` is `ROOT` or `INTERMEDIATE`. Page numbers start at 1; values below 1 fall back to page 1 and size 10.

On success:
```json
{
  "response": {
    "pageNumber": 1, "pageSize": 10, "totalRecords": 1, "totalPages": 1,
    "allPartnerCertificates": [
      { "caCertificateType": "ROOT", "partnerDomain": "AUTH", "certId": "1f2e....",
        "issuedTo": "CN=...,O=...", "issuedBy": "CN=...,O=...", "certThumbprint": "<sha-1 hex>",
        "validFromDate": "2026-11-10T00:00:00.000Z", "validTillDate": "2028-11-09T00:00:00.000Z",
        "uploadTime": "2026-11-10T10:00:00.000Z", "status": true }
    ]
  },
  "errors": null
}
```
`status` is true while the certificate is inside its validity window. Failures come back in `errors[]` with HTTP 200: `KER-PCM-018` (unknown type), `KER-PCM-011` (domain not allowed), `KER-KMS-005` (unreadable body, e.g. a bad date).

**Who can call it**

Only PARTNER_ADMIN (default configuration) — not GLOBAL_ADMIN or PMS_ADMIN. Anyone else is refused. See README.md § How authentication works in this module.
