**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Grants authentication features to a partner's license key. After a TSP (an authentication partner) has been issued a license key with `POST /license/generate`, this call attaches permissions to it — for example "OTP Trigger", "Demo Authentication - Identity Data Match" or "eKYC - Full". Only values from the configured master list are accepted. Calling it again adds the new permissions to the ones already stored.

**Request & response**

```json
{
  "id": "string",
  "version": "string",
  "requesttime": "2026-11-11T10:00:00.000Z",
  "request": {
    "tspId": "TSP001",
    "licenseKey": "aB3dE5gH7jK9mN1p",
    "permissions": ["OTP Trigger", "eKYC - Full"]
  }
}
```
On success:
```json
{ "response": { "status": "Mapped License with the permissions" }, "errors": null }
```
Errors come back with HTTP 200 and an `errors` list: `KER-LKM-001`/`KER-LKM-006`/`KER-LKM-007` blank TSP ID / license key / permission, `KER-LKM-003` permission not in the master list, `KER-LKM-004` key not issued to that TSP. There is no expiry check here, so permissions can still be added to an expired key.

**Who can call it**

Any logged-in user — there is no role rule on this endpoint (row _003 flags this as a possible bug). See README.md § How authentication works in this module.
