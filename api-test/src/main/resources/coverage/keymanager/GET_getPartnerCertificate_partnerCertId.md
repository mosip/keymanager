**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Returns the MOSIP-signed copy of a partner's certificate. When a partner uploads its own CA-signed certificate, the key manager issues a new certificate for the same key, signed by MOSIP's partner-signing (PMS) key; this endpoint hands that MOSIP-signed copy back, so systems that only trust MOSIP can use the partner's key.

**Request & response**

A plain `GET` with the partner certificate ID returned by uploadPartnerCertificate:
```
GET /v1/keymanager/getPartnerCertificate/7a6b5c4d-....
```
On success:
```json
{
  "response": {
    "certificateData": "-----BEGIN CERTIFICATE-----\n...",
    "timestamp": "2026-11-10T10:05:00.000Z"
  },
  "errors": null
}
```
Failures come back in `errors[]` with HTTP 200: `KER-PCM-010` (blank ID), `KER-PCM-012` (no partner certificate with that ID).

**Who can call it**

ZONAL_ADMIN, GLOBAL_ADMIN, PMS_ADMIN and PMS_USER (default configuration). Anyone else is refused. See README.md § How authentication works in this module.
