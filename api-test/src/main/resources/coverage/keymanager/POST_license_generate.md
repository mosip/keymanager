**About this endpoint**

**What this endpoint does**

Issues a new license key to a TSP (an authentication partner). The key is a random 16-character code with an expiry time. On its own it grants nothing — permissions are attached afterwards with `POST /license/permission`, and they can be read back with `GET /license/permission`. Every call issues a new key.

**Request & response**

```json
{
  "id": "string",
  "version": "string",
  "requesttime": "2026-11-11T10:00:00.000Z",
  "request": {
    "tspId": "TSP001",
    "licenseExpiryTime": "2026-12-31T23:59:59.000Z"
  }
}
```
`licenseExpiryTime` is UTC and must be later than now. On success:
```json
{ "response": { "licenseKey": "aB3dE5gH7jK9mN1p" }, "errors": null }
```
Errors come back with HTTP 200 and an `errors` list: `KER-LKM-001` blank TSP ID, `KER-LKM-008` expiry in the past, `KER-KMS-005` unreadable request (e.g. wrong date format). A missing expiry currently gives HTTP 500 (row _010).

**Who can call it**

ZONAL_ADMIN, GLOBAL_ADMIN, INDIVIDUAL, ID_AUTHENTICATION, TEST, REGISTRATION_ADMIN, REGISTRATION_SUPERVISOR, REGISTRATION_OFFICER, REGISTRATION_PROCESSOR, PRE_REGISTRATION_ADMIN and RESIDENT (default configuration). Anyone else is refused. See README.md § How authentication works in this module.
